    HOW AN INVESTIGATION RUNS STEP-BY-STEP
    🛡️ Safety Agent
    Checks truck sensors (engine heat, tyre pressure) and flags driver safety threats.
    🔧 Maintenance Agent
    Checks repair records to make sure the truck is not overdue for service.
    🚚 Operations Agent
    Checks delivery deadlines, driver shift hours, and urgent cargo priorities.
    ⚖️ Critic Agent
    Double-checks all facts to make sure no AI agent made up false statements.
    🔺 Red Team Agent
    Plays "Devil's Advocate" to search for hidden dangers before giving approval.
    ✅ Policy Guard
    Automatically pauses high-risk trucks until a human operator approves.
